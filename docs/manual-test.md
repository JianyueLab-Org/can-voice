# can-voice 手工测试

给人坐下来测的清单，不是 CI。单元测试和 e2e 夹具测不到的东西都在这里：真声卡、真票、真距离、真顶号、真通播机队。

**和现在的 Mumble 不通。** 同一个频率上两套系统互相听不见。测的时候两边都要开 can-voice，或者一个人继续守着老客户端当对照。

**不要在有人值班时停 Murmur。** 切流是全网一件事，这份清单测的是 can-voice 自己能不能用，不是把生产切过去。

发出去的都是预发布，最新一个是 `v27.0.7`（2026-09-20），正文写着客户端没连过真实语音服务端。
**这句话到今天仍然成立**：文末那张记录表是空的，没有任何一次真实环境的验证被记下来过。测完就记在那里。

## 你要准备什么

| 要什么 | 最低 | 完整一场 |
|---|---|---|
| 已定级成员账号 | 2 个（不同 CID） | 3 个 |
| 电脑 | 1 台（两个客户端 + 耳机防啸叫） | 2 台，分处不同城市更好（测射程） |
| 客户端 | `audio-for-can` + 一个飞行员端 | 四个都装：`audio-for-can` / `atis-for-can` / `xpc-for-can` 或 `msfs-for-can` |
| 语音服务端 | 已经在 `audio.ceruleanavi.net:64738/udp` 上，或本机 compose | 同上，外加机队容器在跑 |
| 模拟器 | 飞行员端才要 | X-Plane 或 MSFS 开着，COM1 调到约定频率 |

账号必须已经定级（rating ≥ 1）。未定级会被拒，界面说的应该是「还没有定级」而不是「密码错了」——`v27.0.7` 及更早的包会说错，main 上已经修好（#70）。

密码不存盘。CAN 号、呼号、机型会预填。

Windows 安装包没签名，会弹「已保护你的电脑」→ 更多信息 → 仍要运行。这是已知的，不是失败。

**main 上有一批还没进任何一个 release 的修**：R5 审计那十一条（#69–#80，PR #88）、QUIC 按对端地址族绑定、四个桌面端的 CSP（PR #92），以及通播让路按发言人计数。
要测这些，从 main 自己打一份包，别用 GitHub release 上那一版。下面 §7 的回归表列的正是它们。

## 最短一场（约 45 分钟）

两个人、两个账号、`audio-for-can` 各开一份就够。约好一个频率，例如 **121.800**。

1. 两个人都能连上，状态是「已连接」。
2. A 按住 PTT 说话，B 听见、RX 灯亮；松开后灯灭、声音停。
3. 对调。
4. 两人同时按 PTT，两边都听见对方（会叠在一起，这是正常的）。
5. A 用同一账号在第二台机器再连一次：第一台应显示「这个账号在别处登录了」，并且**不再自己重连回去互踢**。
6. 错密码：应说凭据不对，不要变成「连不上服务器」。
7. 未定级账号：应被拒。记下它说的那句话（#70）。

这 7 条全过，语音平面能用。通播、飞行员、观察员、交叉耦合是下一档。

## 约定

全文用这几个位置，免得各测各的：

| 角色 | 客户端 | 频率 | 备注 |
|---|---|---|---|
| 管制 A | `audio-for-can` | 121.800 TX+RX，118.000 只 RX | 需要先在 EuroScope / CRC 上这个频率的席位，否则客户端会关掉发射（「你此刻不在任何席位上」） |
| 管制 B | `audio-for-can` | 121.800 TX+RX | 第二个账号 |
| 飞行员 | `xpc-for-can` 或 `msfs-for-can` | COM1 = 121.800 | 要开模拟器 |
| 观察员 | 同上，勾「观察员模式」 | 手输 121.800 或跟 COM1 | **必须用第三个账号**，跟上飞行员会把飞行员顶掉 |
| 通播制作 | `atis-for-can` | 例如 127.2 之类真实 ATIS 频率 | 这支**不出声** |
| 通播声音 | 服务端机队 | datafeed 里每一个 `_ATIS` | 桌面那支出声就是失败 |

测交叉耦合时把 121.800 和 121.600 耦成一对。

## 1. 连上

### 1.1 正常登录

- 打开 `audio-for-can`：连上之前是一张独立的登录页，居中一张 340px 的卡片，CAN 号预填成上次那个，密码永远是空的。填密码，点「连接」。
- 通过：很快变成「已连接」，登录卡片换成台面，能看到 RTT。
- 失败形态：一直「连接中」、变成「已断开」、或「服务端拒绝了这次连接」。后一种先看是不是没配换票密钥（can-api 的 `VOICE_TOKEN_KEY` / 服务端的 `CAN_VOICE_API_PUBKEY`）。

### 1.2 地址

默认就是生产地址（`api.ceruleanavi.net` / `audio.ceruleanavi.net:64738`）。测本机时：设置 → 服务器地址，语音服务器填 `127.0.0.1:64738`，TLS 名用证书上的那个主机名（本机自签时走 e2e 夹具，桌面端没有「跳过证书」开关，本机桌面测生产证书更省事）。

- 留空 = 用默认。保存后再连才生效。

### 1.3 错密码 / 未定级 / 版本

| 做 | 通过 |
|---|---|
| 密码打错 | 说 CAN 号或密码不对，不是「连不上」 |
| 未定级账号 | 被拒。理想情况**不要**说成密码错（#70，现网可能仍错） |
| 故意把客户端指到一个旧协议的服务端 | 「客户端版本太旧，请更新后再连」 |

### 1.4 顶号

同一 CID 在第二台机器再连。

- 通过：先连的那台显示「这个账号在别处登录了，语音已断开」，PTT 不再出声；后连的那台正常。先连的那台**不会**过几秒又顶回来。
- 失败：两台来回踢，两边都显示已连接。

### 1.5 精简模式和窗口最小尺寸

- 窗口往小了拖：停在 620×480 附近，拖不进比这更小。
- 点顶栏「精简」：收成一列卡片，窗口跟着缩到大约 248×186；加频率那一行、在线一览、底栏和「设置」按钮都不见了；「置顶」「精简」两个按钮变成约 30×26 的方块，字变成「顶」「简」。
- 再点一次「精简」：窗口退回不小于 620×480，刚才那些东西都回来了。

## 2. 通话（管制）

管制端在 EuroScope / CRC 上到对应席位之前，发射是关的（「你此刻不在任何席位上，不能发射」），但还听得见。测发射前先上席位，等最多一分钟让 datafeed 跟上。

### 2.1 单通

A 按住 PTT（或界面上的按住发话）说一句，松开。

- 通过：B 听见、对应频率 RX 灯亮；松开后灯在约 0.1 秒内灭，没有半秒拖尾，也没有灯常亮。
- 自己不应听见自己（没有 RTT 回声）。

### 2.2 对讲

对调再来一次。再同时按。叠音是正常的。

### 2.3 中途加频率

台面下面那一行：频率格 1 份、呼号格 2 份、加号按钮定宽，旁边没有设置入口了（设置在顶栏「设置」按钮里，见 2.6）。

A 说话说到一半，B 才把 121.800 加进台面。

- 通过：B **立刻**听见后半句，不是等 A 下一次按 PTT。
- 失败：B 一声不响，直到 A 松手再按。服务端日志看起来会是正常的。
- 顺便测：频率格里填一个波段外的数字（比如 `999.000`）回车。通过：右上角弹出一条提示，4 秒后自己消失，不是台面里一条常驻的横条；连着打错两次，提示要重新出现（不能第二次就不弹了）。

### 2.4 交叉耦合

A 的台面：121.800 TX+RX，121.600 TX+RX，两个之间开 XC。B 只守 121.600。

- 通过：A 在 121.800 上说话，B 在 121.600 上听见，而且只有一份（没有回声）。
- A 自己在 121.600 那一行不应再听到自己。

### 2.5 PTT

| 做 | 通过 |
|---|---|
| 绑一个键盘键 | 按住发、松开停。那个键在别的程序里仍然有效（没有被吞掉） |
| 绑鼠标侧键 | 同上（系统不支持会说明） |
| 手柄按钮 | 同上 |
| Linux Wayland | 键盘 PTT 可以不响；手柄和界面按钮必须还能用 |
| 松手 | 不得常开麦克风 |

### 2.6 音频设备

选设备不在台面上了，在顶栏「设置」→「音频设备」里。先试一遍：设置 → 音频设备，切一下麦克风/耳机，点「试听喇叭」「试听麦克风」应该都还响。

拔掉正在用的耳机/麦，再插上。

- 通过：出现「声卡不见了…」之类提示，重开之后又能听又能说，不必重连。

## 3. 飞行员

`xpc-for-can` 或 `msfs-for-can`。COM1 调到 121.800，电门打开。

### 3.1 能说话

飞行员按 PTT，管制听见；管制说话，飞行员听见。COM1 电门关掉，飞行员应听不见、也发不出（观察员手输频率除外）。

### 3.2 他机

- X-Plane：没装 `PI_XpcTraffic.py` 时天上是空的，但语音仍应可用。装上之后能看见别人。客户端「本机 → X-Plane 他机插件」装不进去时，界面会给出文件位置。
- MSFS：能看见别人。机型对不上时落到 C172 之类默认机模是已知的，不算失败。

### 3.3 观察员

飞行员用账号 1 上线。观察员勾「观察员模式」，填跟随呼号（飞行员那架），**用账号 2**，手输 121.800。

- 通过：观察员能听能说，网络上**没有**第二架飞机，不能拍发计划。
- 连接期间改不了观察员开关（「连接期间不能切换观察员模式」）。
- 观察员用飞行员同一个账号：飞行员会被顶掉。这是对的。
- 清空手输频率：改跟 COM1。COM1 没开时可以没有频率，不要猜一个。

### 3.4 服务端通知

和 2.6 同一条展示路径，飞行员端此前一处都不画（#91）。

拔掉正在用的耳机/麦，再插上。

- 通过：界面上出现「声卡不见了…」，重开之后自己消失，不必重连。精简模式下也要看得见。
- 射程过滤降级（服务端 `range_unavailable`）时同样有一条横幅。

## 4. 通播

声音归服务端机队，桌面 `atis-for-can` 只做稿子、挂 FSD、发文字。同一频率两个声音就是失败。

### 4.1 桌面不出声

`atis-for-can` 上线一个 `_ATIS` 席位。管制守那个频率。

- 通过：文字通播在 FSD 上能查到；**桌面这支自己不往语音里出声**。
- 有声音：要么机队也在播（这是要的），要么桌面也连了语音（这是 bug）。机队关掉再测一次就能分清。

### 4.2 机队出声

机队容器在跑，datafeed 里有至少一个 `_ATIS`。管制守那个频率，别按 PTT。

- 通过：能循环听到通播，两轮之间大约空 3 秒。念的是电码原文（`09004MPS` → "zero niner zero zero four MPS"），不是口语稿。这是设计，不是失败。
- 停掉机队：声音停。再拉起来：声音恢复，不必重开桌面客户端。

### 4.3 让路

通播正在念，管制在同一频率按 PTT 说话。

- 通过：通播立刻让开，管制的话能听清；说完后通播从**下一轮开头**再念，不会从半句接上。
- 两个人先后说话（第二个还没说完，第一个已经松手）：通播仍应让着，**不要**压到还在说话的人身上。`v27.0.3` 这一条会失败，当前工作区已修。

### 4.4 多席位

datafeed 里同时有两个 `_ATIS`（比如 ZSPD 和 ZSSS）。

- 通过：两个频率都有声音，不会互相把对方踢下线（两端日志都写着「成功」却只剩一路，就是这个）。
- 改一份 `text_atis`：下一轮换稿，不必重连。

### 4.5 桌面稿子

`atis-for-can` 里：取真实报文、看文字通播 / 英文语音稿 / 中文语音稿是否像那么回事。上线后 FSD 上的文字和预览一致。导入 vATIS、并入全网配置：正在播出的席位这次不会被覆盖。

不带 `|` 的纯中文稿，机队现在可能用英文嗓子念（#71）。记下，不必当场当成新 bug。

## 5. 射程

两个人、两个账号，一个在席位附近，一个远在 vis range 之外（或模拟器里把飞机飞远）。

- 通过：近的听得见，远的听不见。飞回来的那一帧开始又能听见（不必等下一次 PTT）。
- 位置服务挂了：客户端应提示射程过滤已关闭，频率变成全网可听，而不是所有人变聋。

观察员没有自己的 FSD 位置，射程按跟随那架飞机算。飞行员飞出射程，观察员应一起听不见。

## 6. 稳定性和排障

| 做 | 通过 |
|---|---|
| 服务端进程重启（compose 重启 `can-voice`） | 客户端走「重连中…」然后恢复，不必手点连接。通播机队自己拉回来 |
| 拔网线几秒再插 | 同上；连续失败太多次桌面端会放弃，机队不会 |
| 设置里改主题 / 置顶 / 精简模式 | 立刻生效，重启还在 |
| 语言切到 English 再切回来 | 界面跟着变，错误那句也跟着变 |
| 日志回传（设置 → 排障） | 把日志发出去，用的是 CAN 号+密码，发出去之后密码框应被清空 |

## 自动更新

**还没有哪一版发布带签名，所以这一节现在走下来会「条条都过」，而其实什么也没发生。**
can-api 那条更新路对没有 `.sig` 的 release 一律回 204，客户端检查完就直接进主界面——和「已经是最新」长得一模一样，分不出来。
等到有一版真的带上签名再照下面走一遍，在那之前不要把这一节记成通过。

自动化不了：要有一个真的旧版在真的机器上自己换成新版。

1. 装上上一个版本（不是这一版）。
2. 确认 `api.ceruleanavi.net` 通。
3. 开一次。应当先看到「正在检查更新…」，然后是下载进度，然后程序自己重启。
4. 重启之后在设置里核对版本号，确认是新的。
5. **Linux 上分两种**：AppImage 走上面这条；deb 和 rpm 应当**不**自动更新，
   而是照旧显示横幅。两种都要走一遍。
6. 断网再开一次。应当**直接进主界面**，不卡、不报错、不弹框。
   这一条比上面任何一条都重要：更新服务挂掉不能让人上不了线。

## 不要当作失败的

- Windows SmartScreen、未签名。
- 没有 macOS 包。
- Wayland 下键盘 PTT 不响（手柄和按钮要响）。
- 通播念电码原文。
- MSFS 他机落到默认机模。
- 没装 X-Plane 插件时天上是空的。
- 桌面通播不出声。
- 和 Mumble 互不相通。
